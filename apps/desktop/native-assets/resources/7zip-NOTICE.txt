The exact upstream corresponding source, including upstream build scripts,
is included as 7z2603-src.tar.xz beside this notice in each Explorie installer:
Windows: licenses/7z2603-src.tar.xz beside Explorie.exe.
macOS: explorie.app/Contents/Resources/licenses/7z2603-src.tar.xz
(Finder: Show Package Contents). The archive can be copied and extracted
with standard archive tools, including the bundled 7-Zip executable.

Explorie communicates with the separately replaceable 7-Zip executable using
its command-line interface. No 7-Zip source changes are made. Windows uses
7zip/7z.exe and 7zip/7z.dll beside Explorie.exe; macOS uses
explorie.app/Contents/Resources/7zip/7zz. macOS distribution code-signs the
upstream executable as part of the app bundle; it does not change its code.
